# Excel-Module-End-Assignment
Analyzed healthcare data to identify patterns in patient health, medical history, and healthcare costs using Excel.

Key Tasks
Cleaned and handled missing/inconsistent data.
Transformed healthcare variables and created Weight Status and Diabetes Status.
Combined three tables using Customer ID and VLOOKUP.
Used Pivot Tables and Charts to analyze health conditions, surgeries, BMI, HbA1C, age, hospital tiers, and healthcare charges.
Built an interactive dashboard with Pie, Bar, Line, and Scatter Charts.
Added Weight Status and Diabetes Status slicers for interactive filtering.
Tools

Microsoft Excel | VLOOKUP | Pivot Tables | Charts | Slicers | Data Cleaning
